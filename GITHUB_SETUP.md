# Configuração sugerida no GitHub

## Nome do repositório

`sieo-web-automation`

## Descrição curta

Automação web em JavaScript para reduzir tarefas repetitivas no Diário de Classe, com foco em DOM dinâmico, controle de estado, debugging e interfaces assíncronas.

## Visibilidade

Para portfólio, use **Público** somente depois de revisar todo o conteúdo e remover dados do ambiente real.

## Tópicos sugeridos

`javascript` `automation` `web-automation` `tampermonkey` `dom` `async-await` `localstorage` `debugging` `portfolio-project`

## Ordem sugerida para publicar

1. Criar o repositório sem marcar a opção de gerar README automaticamente.
2. Enviar o conteúdo desta pasta.
3. Conferir se as imagens aparecem no README.
4. Revisar a pasta `demo/`.
5. Conferir se nenhum arquivo contém nome de escola, aluno, professor, login, cookie ou token.
6. Adicionar o repositório à seção "Projetos" do LinkedIn.
7. Usar a URL do repositório no campo "Link" do projeto no LinkedIn.

## Sugestão de título no LinkedIn

**Automação Web para Diário de Classe - SIEO**

## Sugestão de descrição curta no LinkedIn

Projeto independente de automação web desenvolvido em JavaScript para reduzir tarefas repetitivas no Diário de Classe. A solução trabalha com navegação por datas, leitura dinâmica do DOM, controle de estado, tratamento de carregamentos assíncronos e persistência com localStorage.
